# Dashboard

## Overview
- The Dashboard is the landing screen when first opening LaborForest
- You can navigate to the Dashboard at any time using the menu on the left

![LaborForest - Dashboard](images/dashboard.png)

## Adding a project
- Add a new `Project` by clicking the green `Add project` button and selecting the root of your project directory
- Your project directory must already be a git repository

## Adding CLI tools
- LaborForest ships with CLI tools to allow adding a `Project` or running a `Workflow` from the command line
- To use the CLI tools, you must first install them (somewhere included in your system `PATH`)
- Read more about LaborForest CLI tools [here](cli-tools.md)

## Reading the Docs
- Clicking `Read the Docs` opens your default web browser with the LaborForest documentation on GitHub
